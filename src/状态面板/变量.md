# 月计都市 — 变量列表

## 世界
| 路径 | 类型 | 说明 |
|------|------|------|
| 世界.时代 | string | 研究所时期 / 脑叶公司时期 / 废墟图书馆时期 / 边狱巴士时期 |
| 世界.地区 | string | 玩家所在地区（自由输入） |

## 玩家
| 路径 | 类型 | 说明 |
|------|------|------|
| 玩家.性别 | string | 男 / 女 |
| 玩家.种族 | string | 自由输入 |
| 玩家.年龄 | string | 自由输入 |
| 玩家.身高 | string | 自由输入 |
| 玩家.职业 | string | 收尾人 / 羽毛 / 帮派 / 小员工 / 普通人 / 老板 / 灾害 |
| 玩家.身份 | string | 自由输入 |
| 玩家.实力 | string | 9~1阶收尾人 / 色彩收尾人 / 文职 / 1~5级员工 / 部门领导 / 精英队长 / 都市传闻~杂质 |
| 玩家.阵营 | string | 食指/拇指/环指/中指/小指 / A~Z公司 / 自定义 |
| 玩家.金钱 | number | 单位：眼。开局由剩余六维点数×100000计算 |
| 玩家.当前年月 | string | 当前游戏内时间 |
| 玩家.所在地区 | string | 当前所在地区 |
| 玩家.外貌 | string[] | 外貌标签数组 |
| 玩家.性格 | string[] | 性格标签数组 |
| 玩家.背景故事 | string | 自由输入 |

## 六维
| 路径 | 类型 | 范围 | 说明 |
|------|------|------|------|
| 玩家.六维.strength | number | 8~15 | 力量：影响物理攻击、格斗 |
| 玩家.六维.agility | number | 8~15 | 敏捷：影响闪避、速度 |
| 玩家.六维.intelligence | number | 8~15 | 智力：影响法术、科技 |
| 玩家.六维.constitution | number | 8~15 | 体质：影响耐力、防御 |
| 玩家.六维.charisma | number | 8~15 | 魅力：影响社交、诱导 |
| 玩家.六维.perception | number | 8~15 | 感知：影响察觉、直觉 |

## 状态
| 路径 | 类型 | 说明 |
|------|------|------|
| 状态.hp.current | number | 当前血量 |
| 状态.hp.max | number | 最大血量 |
| 状态.sanity.current | number | 当前理智 |
| 状态.sanity.max | number | 最大理智 |
| 状态.physical_state | string | 生理状态（正常/受伤/无反抗能力...） |
| 状态.emotion_level | string | 情感等级 |
| 状态.current_form | string | 当前形态 |

## 装备（穿戴中）
| 路径 | 类型 | 说明 |
|------|------|------|
| 装备.weapon | string | 武器名称 |
| 装备.accessory | string | 饰品名称 |
| 装备.top | string | 上装名称 |
| 装备.bottom | string | 下装名称 |
| 装备.shoes | string | 鞋子名称 |

## 身体部位
对每个部位（head/chest/left_arm/right_arm/left_leg/right_leg）:
| 路径 | 类型 | 说明 |
|------|------|------|
| 身体.{部位}.status | string | 状态（正常/受伤/无） |
| 身体.{部位}.armor | string | 护甲名 |
| 身体.{部位}.modification | string | 改造类型（原生/机械/生物） |

## 技能列表
数组，每项：
| 字段 | 类型 | 说明 |
|------|------|------|
| name | string | 技能名称 |
| attr | string | 判定属性（strength/agility/intelligence/constitution/charisma/perception） |
| value | string | 数值（伤害/威力/范围等） |
| vfx | string | 特效描述 |
| appearance | string | 外观描述 |
| effect | string | 效果描述 |

## 装备清单（自定义创建）
数组，每项：
| 字段 | 类型 | 说明 |
|------|------|------|
| name | string | 装备名称 |
| value | string | 数值（攻击/防御/加成等） |
| vfx | string | 特效描述 |
| appearance | string | 外观描述 |
| effect | string | 效果描述 |

## 同伴
数组，每项：
| 字段 | 类型 | 说明 |
|------|------|------|
| name | string | 名字 |
| identity | string | 身份（同伴/俘虏） |
| affection | number | 好感度 |
| current_form | string | 当前形态 |
| hp | {current, max} | 血量 |
| sanity | {current, max} | 理智 |
| physical_state | string | 生理状态 |
| emotion_level | string | 情感等级 |

| body | object | 身体部位（同玩家身体结构） |

## 战斗判定
| 变量 | 值 | 说明 |
|------|------|------|
| 玩家攻击阈值 | 技能属性×5 + 武器修正(15) | 1d100 ≤ 阈值为命中 |
| 敌人攻击阈值 | 50 | 固定值 |
| 玩家命中伤害 | 25 | 命中时敌人扣血 |
| 玩家失误伤害 | 8 | 失手时玩家扣血 |
| 敌人命中伤害 | 15 | 命中时玩家扣血 |
| 敌人失误伤害 | 5 | 失手时敌人扣血 |

## 经济

|------|------|
| 初始金钱 | 六维剩余点数 × 100,000 眼 |

| 六维购点消耗 | 8→13 每点耗1；14耗2；15耗3 |
